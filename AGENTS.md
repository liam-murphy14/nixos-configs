# AGENTS.md

## Repository overview

This repository contains a Nix flake for managing NixOS, nix-darwin, and
standalone Home Manager configurations. The flake tracks `nixos-unstable` and
also provides reusable modules for common services and developer tooling.

The main flake outputs are:

- `nixosConfigurations.rbpi-nixos` — the Raspberry Pi NixOS system
  (`aarch64-linux`).
- `darwinConfigurations.mba-nix-darwin` — the Apple Silicon macOS system
  (`aarch64-darwin`).
- `homeConfigurations.murplia-mac` — standalone Home Manager for Apple
  Silicon macOS.
- `homeConfigurations.murplia-cloud` — standalone Home Manager for ARM Linux.
- `homeConfigurations.murplia-86-cloud` — standalone Home Manager for x86_64
  Linux.

## Directory layout

- `flake.nix` / `flake.lock` — inputs and system/home configuration outputs.
- `rbpi/` — Raspberry Pi NixOS configuration, hardware settings, and secrets
  integration.
- `mba_nix_darwin/` — nix-darwin configuration for the MacBook Air, including
  Homebrew GUI applications.
- `zon_home/` — shared standalone Home Manager configuration for cloud and
  work environments.
- `home_manager_configs/` — reusable Home Manager modules for zsh, Neovim,
  Git, tmux, Python, VS Code, and related tools.
- `nix_modules/` — reusable NixOS modules, including PostgreSQL/PgBouncer,
  Housefire, DDNS, and core Nix settings.

## Common commands

Run commands from the repository root:

```sh
# Format Nix files with the flake's configured formatter.
nix fmt

# Evaluate the flake checks.
nix flake check

# Inspect available flake outputs.
nix flake show

# Build or activate a target on the matching machine.
sudo nixos-rebuild build --flake .#rbpi-nixos
sudo nixos-rebuild switch --flake .#rbpi-nixos
sudo darwin-rebuild build --flake .#mba-nix-darwin
sudo darwin-rebuild switch --flake .#mba-nix-darwin
home-manager build --flake .#murplia-mac
home-manager switch --flake .#murplia-mac
```

Use the corresponding `homeConfigurations` target for the other standalone
Home Manager environments. Prefer building and checking a configuration
before switching it.

## Change guidelines

- Keep reusable behavior in `home_manager_configs/` or `nix_modules/` rather
  than duplicating it in a host configuration.
- Preserve the existing two-space Nix formatting and run `nix fmt` after edits.
- Treat `rbpi/secrets.nix` and everything under `rbpi/secrets/` as sensitive.
  Never expose secret values in documentation, logs, or commit messages.
- `rbpi/hardware-configuration.nix` is generated by NixOS hardware detection;
  change it only when intentionally updating the host's hardware definition.
- Keep `flake.lock` in sync when intentionally updating flake inputs, and
  review the resulting dependency changes.

There is no separate application test suite in this repository. For
configuration changes, formatting, `nix flake check`, and a target-specific
build are the primary verification steps.
